# 单体温度过高诊断

## 先回答的问题
是整个储能单元都在升温（散热系统问题），还是只有这一簇（簇内局部问题）？

## 步骤
1. `get_cluster_extremes(<储能单元ID>, at=<峰值时刻>)`：看同单元各簇最高温度。
   - 超过 40°C 的簇 ≥ 3 个，且中位数明显高于平时 → 按「整舱散热」排查。
   - 只有本簇偏高 → 按「单簇局部」排查（冷板支路、阀门、连接排发热）。
2. 整舱散热：`query_telemetry(<单元>-TMS, coolant_flow)` 和 `pump_current`。
   流量比额定低 30% 以上、水泵电流同步下降 → 优先怀疑过滤器堵塞 / 水泵故障 / 缺液。
3. `get_maintenance_records(<单元>-TMS)`：保养是否超期。
4. `search_fault_cases`：用「液冷 流量 温升 过滤器」等关键词找相似案例。

## 处置原则
- 最高温度达到簇的一级阈值（见设备台账 thresholds.cell_temp_max_l1）→ 建议停机，不要等。
- 未到一级阈值 → 建议降功率运行、派单检查液冷，恢复后复核本簇是否仍比同单元其他簇高。
- 智能体只给建议，不下发任何控制指令。
