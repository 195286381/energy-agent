# 单体压差过大诊断

BMS 只上送簇级极值（最高/最低单体电压和位置），没有全量单体数据，结论要按这个粒度说。

## 步骤
1. `get_cluster_extremes(<簇ID>)`：看最近 7 次充电末端压差趋势和最低单体位置。
   - 同一位置反复最低、压差逐日上升 → 一致性衰减（容量衰减 / 自放电偏大）。
   - 位置每次不同 → 更可能是采样或均衡问题。
2. `query_telemetry(<簇ID>, cell_temp_max)`：排除温差引起的压差（温度正常则排除）。
3. `get_maintenance_records(<簇ID>)`：看内阻抽检有没有提到同一模组。
4. `search_fault_cases`：关键词「压差 一致性 充电末端」。

## 处置原则
- 压差未到二级阈值、温度正常 → 不需要停机；安排容量标定和均衡，持续跟踪趋势。
- 按目前每次上升的速度估算何时触及二级阈值，给出复查时间。
