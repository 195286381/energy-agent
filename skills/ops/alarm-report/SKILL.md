# 告警处置报告格式

最终答复用下面的结构，用中文，短句：

```
## 分诊
告警等级 · 处理优先级（P1 立即 / P2 2 小时内 / P3 当班巡检）· 是否抖动 · 关联告警

## 诊断结论
一句话结论 + 置信度（高 / 中 / 低）

## 关键证据
- 每条证据都要带数值和来源工具，数值只能来自工具结果

## 处置建议
1. 立即要做的
2. 派单检查什么
3. 什么情况升级

## 推送
说明推送草稿已生成，等值班员确认后发送
```

## 推送草稿
调用 `draft_wecom_message`：title 用「设备 + 告警名」，conclusion 一句话，actions 不超过 3 条。
P3 且抖动类告警不需要 @值班长。

## 红线
- 不编造数值；没有数据就写「待确认」。
- 智能体只读，不下发任何控制指令，只给建议。
